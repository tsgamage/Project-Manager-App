# Shadcn UI Component Library - LLM Documentation

## Overview
Shadcn UI is a collection of reusable components built on top of Radix UI and Tailwind CSS. This documentation provides detailed information about each component's purpose, anatomy, properties, events, and usage examples.

---

## Accordion

### When to Use / Purpose
- Display collapsible content sections
- Organize information into expandable/collapsible groups
- Create FAQ sections or navigation menus
- Show/hide detailed information without cluttering the interface

### Anatomy
```tsx
<Accordion>
  <AccordionItem>
    <AccordionTrigger>Trigger Text</AccordionTrigger>
    <AccordionContent>Content</AccordionContent>
  </AccordionItem>
</Accordion>
```

### Properties
- `type`: "single" | "multiple" - Controls whether one or multiple items can be open
- `collapsible`: boolean - Allows all items to be closed when type is "single"
- `value`: string | string[] - Controlled value for open items
- `onValueChange`: function - Callback when value changes
- `disabled`: boolean - Disables the accordion

### Events
- `onValueChange`: Fired when accordion items are opened/closed
- `onClick`: Fired when trigger is clicked

### Example Usages
```tsx
// Single accordion
<Accordion type="single" collapsible>
  <AccordionItem value="item-1">
    <AccordionTrigger>What is Shadcn UI?</AccordionTrigger>
    <AccordionContent>
      Shadcn UI is a collection of reusable components built on Radix UI.
    </AccordionContent>
  </AccordionItem>
</Accordion>

// Multiple accordion
<Accordion type="multiple">
  <AccordionItem value="item-1">
    <AccordionTrigger>Installation</AccordionTrigger>
    <AccordionContent>Installation instructions...</AccordionContent>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Usage</AccordionTrigger>
    <AccordionContent>Usage examples...</AccordionContent>
  </AccordionItem>
</Accordion>
```

## Calendar

### When to Use / Purpose
- Display dates in a calendar format
- Allow date selection for forms
- Show event schedules or availability
- Provide date navigation and viewing

### Anatomy
```tsx
<Calendar
  mode="single"
  selected={date}
  onSelect={setDate}
  className="rounded-md border"
/>
```

### Properties
- `mode`: "single" | "multiple" | "range" - Selection mode
- `selected`: Date | Date[] | DateRange - Selected date(s)
- `onSelect`: function - Callback when date is selected
- `disabled`: Date[] - Disabled dates
- `fromDate`: Date - Minimum selectable date
- `toDate`: Date - Maximum selectable date
- `defaultMonth`: Date - Initial month to display

### Events
- `onSelect`: Fired when date is selected
- `onMonthChange`: Fired when month changes

### Example Usages
```tsx
// Single date selection
const [date, setDate] = useState<Date>()

<Calendar
  mode="single"
  selected={date}
  onSelect={setDate}
  className="rounded-md border"
/>

// Date range selection
const [dateRange, setDateRange] = useState<DateRange>()

<Calendar
  mode="range"
  selected={dateRange}
  onSelect={setDateRange}
  numberOfMonths={2}
/>

// With disabled dates
<Calendar
  mode="single"
  selected={date}
  onSelect={setDate}
  disabled={(date) => date < new Date()}
/>
```

```tsx
  checked={checked}
  onCheckedChange={setChecked}
/>
```

## Form

### When to Use / Purpose
- Create structured form layouts
- Handle form validation and submission
- Provide consistent form styling
- Manage form state and errors using native HTML forms

### Anatomy
```tsx
<form onSubmit={handleSubmit} className="space-y-6">
  <div className="space-y-2">
    <Label htmlFor="email">Email</Label>
    <Input id="email" name="email" type="email" required />
  </div>
  <Button type="submit">Submit</Button>
</form>
```

### Properties
- `onSubmit`: function - Form submission handler
- `className`: string - Additional CSS classes
- `method`: "GET" | "POST" - HTTP method (default: "POST")
- `action`: string - Form action URL
- `encType`: string - Form encoding type

### Events
- `onSubmit`: Fired when form is submitted
- `onChange`: Fired when form inputs change
- `onReset`: Fired when form is reset

### Example Usages
```tsx
// Basic form with native validation
function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
  event.preventDefault()
  const formData = new FormData(event.currentTarget)
  const email = formData.get('email')
  const password = formData.get('password')
  
  // Handle form submission
  console.log({ email, password })
}

<form onSubmit={handleSubmit} className="space-y-6">
  <div className="space-y-2">
    <Label htmlFor="email">Email</Label>
    <Input 
      id="email" 
      name="email" 
      type="email" 
      placeholder="Enter your email" 
      required 
    />
  </div>
  <div className="space-y-2">
    <Label htmlFor="password">Password</Label>
    <Input 
      id="password"

const [errors, setErrors] = useState<Record<string, string>>({})

function validateForm(formData: FormData) {
  const newErrors: Record<string, string> = {}
  
  const email = formData.get('email') as string
  if (!email) {
    newErrors.email = 'Email is required'
  } else if (!email.includes('@')) {
    newErrors.email = 'Email must be valid'
  }
  
  const password = formData.get('password') as string
  if (!password) {
    newErrors.password = 'Password is required'
  } else if (password.length < 6) {
    newErrors.password = 'Password must be at least 6 characters'
  }
  
  return newErrors
}

function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
  event.preventDefault()
  const formData = new FormData(event.currentTarget)
  const newErrors = validateForm(formData)
  
  if (Object.keys(newErrors).length === 0) {
    // Form is valid, proceed with submission
    console.log('Form submitted successfully')
  } else {
    setErrors(newErrors)
  }
}
```

## Tooltip

### When to Use / Purpose
- Show additional information on hover
- Provide context for UI elements
- Display helpful hints or explanations
- Create accessible help text

### Anatomy
```tsx
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger>Trigger</TooltipTrigger>
    <TooltipContent>Content</TooltipContent>
  </Tooltip>
</TooltipProvider>
```

### Properties
- `open`: boolean - Controls tooltip visibility
- `onOpenChange`: function - Callback when open state changes
- `delayDuration`: number - Delay before showing tooltip (ms)
- `skipDelayDuration`: number - Delay before hiding tooltip (ms)

### Events
- `onOpenChange`: Fired when tooltip opens/closes

### Example Usages
```tsx
// Basic tooltip
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="outline">Hover me</Button>
    </TooltipTrigger>
    <TooltipContent>
      <p>Add to library</p>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>

// Tooltip with icon
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="ghost" size="icon">
        <HelpCircle className="h-4 w-4" />
      </Button>
    </TooltipTrigger>
    <TooltipContent>
      <p>Click to get help</p>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>

// Tooltip with custom delay
<TooltipProvider delayDuration={1000}>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button>Long delay tooltip</Button>
    </TooltipTrigger>
    <TooltipContent>
      <p>This tooltip appears after 1 second</p>
    </TooltipContent>
  </Tooltip>
</TooltipProvider>

// Multiple tooltips
<TooltipProvider>
  <div className="flex items-center space-x-2">
    <Tooltip>
      <TooltipTrigger asChild>
        <Button variant="outline">Save</Button>
      </TooltipTrigger>
      <TooltipContent>
        <p>Save your changes</p>
      </TooltipContent>
    </Tooltip>
    <Tooltip>
      <TooltipTrigger asChild>
        <Button variant="outline">Cancel</Button>
      </TooltipTrigger>
      <TooltipContent>
        <p>Discard your changes</p>
      </TooltipContent>
    </Tooltip>
  </div>
</TooltipProvider>

// Tooltip with rich content
<TooltipProvider>
  <Tooltip>
    <TooltipTrigger asChild>
      <Button variant="outline">User Info</Button>
    </TooltipTrigger>
    <TooltipContent className="w-80">
      <div className="space-y-2">
        <h4 className="font-semibold">John Doe</h4>
        <p className="text-sm text-muted-foreground">
          Software Engineer at Example Corp

      </div>
    </TooltipContent>
  </Tooltip>
```
